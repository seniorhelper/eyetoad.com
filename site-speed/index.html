Direct answer: Lighthouse is Google's open-source tool that scores a page from 0 to 100 on performance, accessibility, best practices and SEO. Google's own PageSpeed Insights runs it. The test on this page calls that API live against eyetoad.com, so the scores you see are the scores Google measured at the moment you clicked, not a screenshot from a good day.

Why we put the test on the page instead of a badge

Every agency website says it is fast. Most of them load a hero video, four tracking scripts and a chat widget before a single word appears. We would rather be checked than believed, which is the same standard we hold our clients' sites to: if the number is good, show the number live; if it is not, fix it.

Speed is not vanity. Google has used page experience in ranking for years, and the Core Web Vitals it measures are the ones Lighthouse reports. More practically, a slow page on a phone loses the visitor before the phone number renders. Our guide to whether website speed affects SEO covers the ranking side; our guide to Core Web Vitals in 2026 covers the metrics.

What we actually did to this site

None of it is exotic. It is a list of small decisions made on every page, which is harder than one big decision made once.

Hand-coded, no page builder

Every page is written as HTML and CSS, not generated by a theme. There is no framework to download before the page can draw.

Critical styles inline, everything else deferred

The styles needed to paint the first screen ship inside the page. Scripts load after the content, and the chat assistant does not load at all until you scroll or tap.

No unused downloads

We audited every preload, image and font on 150 pages and removed the ones nothing used, including a 387 KB image that dozens of pages were downloading for no reason.

Right-sized images

Logos and screenshots are served at the size they display, in modern formats, with dimensions declared so nothing jumps while loading.

No layout thrash

Scroll handlers never force the browser to re-measure the page on every frame. Animations use transform and opacity so they run on the compositor, and they stop under reduced-motion settings.

Accessible by default

Color contrast meets WCAG AA, links are distinguishable without color, headings follow a logical order and every control works from a keyboard. That is the accessibility ring, and it is also just good manners.

✓Every page on this site is checked in a real browser on a 390-pixel phone and a desktop before it ships.

What it would take to do this for your site

Usually less than a rebuild. Most slow sites are slow because of three or four things: a theme that loads everything, images that were never resized, and scripts that nobody remembers adding. A technical pass fixes those in days. Sites built on a page builder that fights every fix are the exception, and that is when we talk about custom website design on the subscribe-to-own model.
