#  blocked path is a chance to accidentally suppress something
#  that matters. (The July 2026 favicon investigation confirmed
#  /images/ is reachable — keep it that way.)
#
#  IF YOU ADD A Disallow LINE, READ THIS FIRST:
#  Disallow stops CRAWLING, not INDEXING. A disallowed URL can
#  still appear in results as a bare link with no snippet, and
#  because Google can no longer fetch the page it will never see
#  a noindex tag there either. To keep a page OUT of the index,
#  use <meta name="robots" content="noindex"> on the page and
#  leave it crawlable. Never use both — they cancel each other.
# ============================================================
